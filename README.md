# Meetup Matchmaker

AI-powered networking for tech meetups. At events with 300+ attendees, most
introductions happen by chance. Scan the event QR code, fill in a short profile
and get the 5 people you should meet, each with a short explanation of why.

## How it works
- **Profile:** role, stack, experience, interests, a short bio, and one goal
  (find a job, hire, find a mentor, become a mentor, find a co-founder,
  exchange experience).
- **Goal-aware matching:** goals are reciprocal. A job seeker is matched with
  people who are hiring, not with other job seekers.
- **Complementary, not similar:** the score is two-sided,
  `sqrt(fit(A->B) * fit(B->A))`, so both people must benefit. Mentors must have
  more experience than mentees; co-founders score higher with different stacks.
- **Multilingual:** kk / ru / en profiles are compared through a multilingual
  embedding model, so a Kazakh bio can match a Russian one.
- **Top 5 with reasons:** every match has an explanation, what each side gives,
  and an icebreaker line.
- **Events:** organizers create an event, people join by QR, matches are shown
  only among that event's attendees, plus a live room map for the projector.
- **Fast:** recommendations in under 3 seconds (usually well under 100 ms).
  Embeddings are computed at startup, no LLM call on the request path.

Details: [`docs/CONTRACT.md`](docs/CONTRACT.md).

## Data
130 synthetic profiles with fictional names in [`data/profiles.json`](data/profiles.json),
generated by [`data/generate_profiles.py`](data/generate_profiles.py) (all 6 goals,
8 tracks, 0-16 years of experience, bios in kk / ru / en). No real profiles are used
or scraped.

```
python data/generate_profiles.py          # rewrite data/profiles.json (deterministic)
python data/generate_events.py            # rewrite data/events.json from the profiles
```

Seed events in [`data/events.json`](data/events.json) are loaded on the first start:
`DEMO` (all 130 people, open), `DEVNIGHT` (103 engineers, open) and `STARTUP`
(76 founders and mentors, closed). Every event has at least 6 people per goal.

Optional LLM texts for dataset pairs go to `data/explanations.json`
(see "Precomputed explanations" in the contract). Without the file the backend uses
instant templates in all three languages.

```
python -m backend.scripts.precompute_explanations --dry-run   # show the pairs
python -m backend.scripts.precompute_explanations             # needs ANTHROPIC_API_KEY in .env
```

## Run

With Docker (needs Docker Desktop running):

```
cp .env.example .env   # set ADMIN_CODE and PUBLIC_URL=http://<your-LAN-IP>:3000
docker compose up --build
```

Open http://localhost:3000 (API on http://localhost:8000/api/health).
The first build downloads the embedding model (about 220 MB) into the image.
The demo event with every profile has the join code `DEMO`; the admin panel is at
`http://localhost:3000/#/admin` (code from `ADMIN_CODE`).

Without Docker (Python 3.12, two terminals, from the repo root):

```
python -m venv .venv
.venv/Scripts/pip install -r backend/requirements.txt     # Windows; use .venv/bin/pip on Linux/macOS
.venv/Scripts/python -m uvicorn backend.app.main:app --port 8000

cd frontend
npm install
npm run dev
```

## Tests

```
pip install -r backend/scripts/requirements.txt
python -m pytest backend/tests -q
```

They check the dataset (100+ profiles, all goals and languages), goal reciprocity
(a job seeker never sees other job seekers), exactly 5 sorted matches for every
profile, and that `/api/recommend` and the QR join answer in under 3 seconds.
`EMBEDDER=hashing` runs them offline in about a second.

## Troubleshooting
- **Python 3.13+ fails to install the pinned packages.** Use Python 3.12, like the Docker image.
- **"Filename too long" on Windows** (git clone or `pip`): run
  `git config --global core.longpaths true` and keep the repo and `.venv` on a short path such as `C:\dev\`.
- **"port is already allocated" on 3000 or 8000.** Another app uses the port. Set `FRONTEND_PORT` / `BACKEND_PORT` in `.env` (and the same port in `PUBLIC_URL`).
- **Phones cannot open the QR link.** Set `PUBLIC_URL` in `.env` to the laptop's LAN address and allow port 3000 in the firewall.
- **Reset events and members:** `docker compose down -v` (or delete `.state/state.json` without Docker).
