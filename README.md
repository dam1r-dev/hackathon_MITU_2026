# Meetup Matchmaker

AI-powered networking for tech meetups. At events with 300+ attendees, most
introductions happen by chance. Fill in a short profile and get the 5 people
you should meet, each with a short explanation of why.

## How it works
- **Profile:** role, stack, experience, interests, a short bio, and one goal
  (find a job, hire, find a mentor, become a mentor, find a co-founder,
  exchange experience).
- **Goal-aware matching:** goals are reciprocal. A job seeker is matched with
  people who are hiring, not with other job seekers.
- **Top 5 with reasons:** every recommendation comes with a 1-2 sentence
  explanation.
- **Fast:** recommendations in under 3 seconds.

## Data
100+ synthetic profiles with fictional names, generated by the team. No real
profiles are used or scraped.

## Run

With Docker:

```
cp .env.example .env   # add your own keys
docker compose up --build
```

Open http://localhost:3000 (API on http://localhost:8000).

Without Docker (two terminals, from the repo root):

```
python -m venv .venv
.venv/Scripts/pip install -r backend/requirements.txt     # Windows; use .venv/bin/pip on Linux/macOS
.venv/Scripts/python -m uvicorn backend.app.main:app --port 8000

cd frontend
npm install
npm run dev
```
