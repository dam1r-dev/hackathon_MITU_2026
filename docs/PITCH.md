# Презентация (10 слайдов, 5-7 минут с живым демо)

Текст на слайдах короткий, остальное говорим голосом. Цифры сверены с репозиторием
(`data/profiles.json`, `backend/tests`). Перед сдачей перепроверь `took_ms` на ноутбуке для демо.

---

### 1. Meetup Matchmaker
- Подзаголовок: «5 людей, с которыми тебе стоит поговорить, за 60 секунд»
- Кейс Qazaq IT Community · AI in Engineering Hackathon 2026 · команда: Дамир, Шахруз, Дулат
- Голосом (10 с): «На митапе 300 человек, а знакомитесь вы с тремя, и случайно».

### 2. Проблема
- 300+ человек на митапе, 2 часа нетворкинга
- Ищущий работу не знает, кто из зала нанимает. Джун не знает, кто готов менторить
- Итог: знакомства случайные, ценные встречи не происходят
- Голосом: пример из жизни команды (одна фраза).

### 3. Решение
- QR на входе → анкета за 60 секунд → топ-5 людей в зале с объяснением «почему»
- Карта зала на проекторе: видно, где твои пятеро
- Кнопка «Хочу познакомиться»: контакт открывается только при взаимном интересе

### 4. Главная идея: полезность, а не похожесть
- Обычный поиск даёт похожих: джуну показывают других джунов
- Мы сводим дополняющих: ищущий работу ↔ нанимающий, ментор ↔ ученик, кофаундеры с разными стеками
- Таблица взаимности 6 целей (из `docs/CONTRACT.md`)

### 5. Как считается скор
- `score(A,B) = sqrt(fit(A→B) · fit(B→A))`, полезно должно быть обеим сторонам
- `fit` = 0, если цели не взаимны; иначе 0.7 · смысловая близость + 0.3 · общие теги
- Ментор должен быть опытнее; кофаундерам плюс за разные стеки
- Мультиязычные эмбеддинги: анкета на казахском находит пару на русском

### 6. Живое демо (2-3 минуты)
- Сценарий: `docs/DEMO.md`
- Если сеть подведёт: заранее записанное видео 3 минуты

### 7. Технологии
- Backend: FastAPI, fastembed (multilingual MiniLM, ONNX на CPU), numpy
- Frontend: React + Vite, mobile-first, kk/ru/en
- LLM (Claude) только офлайн: заранее генерирует объяснения и первые фразы, на запросе LLM нет
- `docker compose up` запускает всё локально

### 8. Качество и данные
- 130 синтетических анкет: 6 целей, 8 направлений, опыт 0-16 лет, био на kk/ru/en. Реальных людей нет
- 22 автотеста: ищущему работу никогда не показываются другие ищущие, всегда ровно 5, ответ < 3 с, полный путь организатора и участника по QR
- Ответ на один запрос: десятки миллисекунд (лимит 3 секунды)

### 9. Для организатора
- Админ создаёт мероприятие, получает QR; организатор управляет своими событиями
- Статистика: «3 нанимающих на 40 ищущих», подсказка, кого позвать
- Обратная связь «познакомились / не подходит» пересчитывает выдачу
